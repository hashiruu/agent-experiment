# 任务队列

## 🥇 FIFO 铁律
用户新给的指令**入队**, 不丢手上正在做的事。除非用户明确说"先停下"。
每条完成后原地标 ✅ 并写上产出(commit / 文件路径), 不要删除 —— 记录本身是可追溯性的一部分。

## ⏸ 阻塞中(等外部输入)
> 关键决策停在这里**等待用户决策**, 但等待期间不许空转 —— 立刻去做队列里不依赖它的下一件事。
> 每条都要写清**在等谁的什么**、**拿到之后要做什么**、以及**等待期间正在推进什么**。
> 不写这一节的话, 这些事会变成"看起来没人管"。

- [ ] 等用户: <具体是什么决定>  → 拿到后: <要做什么>  → 等待期间在做: <队列里的哪一件>

## 📌 已取消
> 取消的也要留痕, 并写清楚为什么 —— 否则下次会有人重新提起。

- ~~<事项>~~ — <日期> 用户决定不做, 原因: <原因>
